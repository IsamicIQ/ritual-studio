# Ritual Studio

Website for Ritual Studio, a pilates studio in Kenya. *Make movement your ritual.*

- `site/` — the static website (deployed to GitHub Pages)
- `site/admin.html` — staff admin preview
- `tools/` — build helpers (frame capture, image grading)

**Status:** Phase 1 preview. Timetable, booking and admin store data in the browser's localStorage (`site/reservas.js`). A real backend (database, staff login, M-Pesa/card payments) is Phase 2.
